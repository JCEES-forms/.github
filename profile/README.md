# JCees Forms

**A flexible form builder for modern JavaScript applications.**

Build and manage forms in one place, then integrate them into your application using React, Vue, Next.js, Nuxt or Vanilla JavaScript.

JCees Forms keeps developers in control of the implementation while giving marketing teams the freedom to create, update and manage forms without relying on development for every change.

**Build once. Manage without code.**

## Works with

- React
- Vue
- Next.js
- Nuxt
- Vanilla JavaScript

Integrate JCees Forms into your application while keeping control over styling, behaviour and the technical implementation.
